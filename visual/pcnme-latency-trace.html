The setup

    What is added up for each task

    L = Tradio + Tin,k + Wqueuek,q + Trunk,q + Tret,k
    Tradioupload from the car to its zone (3.1) Tin,kforwarding to option k (3.2) Wqueuewaiting for a free slot (3.3) Trunrunning on the slot (3.4) Tret,kresult back to the car (3.2)

    When is a task on time?

    A hard task (T1, T3) is on time if L ≤ D; otherwise it is dropped. A soft task (T4, T2) is on time if L ≤ D, late if L ≤ D + Lmax, otherwise dropped. A task that no option can serve in time is dropped at the anchor before it is sent.

    What this example simplifies

    One anchor zone with one neighbour (Nb1) and the cloud. Nb1 has its own cars at the same S3 load, placed on Nb1 itself and not listed here. The choice uses a greedy rule: the option with the smallest estimated finish among those that pass the masks. PCNME's agent chooses with its 48 inputs instead, but every estimate it sees is computed the same way. The anchor sees Nb1's state exactly (no 100 ms staleness), cars do not move, and no message is lost. Run times are drawn from the lognormal of each time-table row. Seed 5, 100 tasks over about 1.5 s.
