What happened

    The rules being animated

    What the node publishes, per slot type q (8.5)

    Remaining mean time on each slot, and the backlog of each class:

    Tremq,j = max(0, tstart + T̄run − t) (0 if slot j is free)
    Ωhardq = Σqueued hard tasks T̄run
    Ωsoftq = Σqueued soft tasks T̄run

    The wait of a new task is 0 while a slot is free (nbusyq < cq); otherwise the water level:

    Σj = 1…cq max(0, Ŵqueueq − Tremq,j) = Ω
    Ω = Ωhardq (new hard task)
    Ω = Ωhardq + Ωsoftq (new soft task)

    A task arrives (8.3)

    Fq = Ŵqueueq + T̄runq
    q* = argminq Fq

    Refused "full" if no usable queue has a place for its class (a soft task needs fewer than nmaxq − nres queued). Refused "late" if t + Fq* > d (hard) or > d + Lmax (soft), or if no slot type here can run it.

    A slot becomes free (8.4)

    1. Skip hopeless heads: hard if t + Trun,lo > d, soft if t + Trun,lo > d + Lmax.
    2. Promote the first soft task if it waited ≥ Tage and every queued hard task still meets its deadline with it on this slot for Trun,hi.
    3. Otherwise the first hard task (earliest deadline first).
    4. Otherwise the first soft task.
    5. Steal from the other queue a task that would finish earlier here: t + T̄runq < its estimated finish there.

    Aborts (8.6)

    A running hard task is aborted when t > d, a soft one when t > d + Lmax. The worker stops at the end of its current step, so the slot stays busy for min(remaining, Tabort) (striped).
