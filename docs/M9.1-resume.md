  probe, `_cancel_attempt`). A "Calls" interface must sit there first (fast-mode impl = today's code, same
  draw order, so the event-log hashes stay the same), then an HTTP impl (httpx client, FastAPI server).

  does the shaping; the zone must still know "send done" and stay single-threaded.
- The testbed deps already exist in pyproject's `testbed` extra (paho-mqtt, fastapi, uvicorn, httpx,
  websockets); the image installs that extra only (no torch), so the integration test uses a rule method.
